# Guion de entrevista

Duración prevista: 40 a 50 minutos. Se pregunta por **hechos y cifras**, no por opiniones.
Si el entrevistado responde «depende», se pide un caso concreto de la última semana.

Antes de empezar: presentarse, explicar para qué se usará la información, pedir permiso para
grabar y para citar la organización (o acordar seudónimo).

## Bloque 1 — La organización y el proceso actual (8 min)

| # | Pregunta | Dato que produce |
|---|---|---|
| P1 | ¿Cuántas personas atienden incidencias y qué rol tiene cada una (mesa de ayuda, técnico de campo, supervisor)? | Número de usuarios por rol |
| P2 | ¿Cuántas incidencias reciben en una semana normal y cuántas en una semana mala? | Volumen base y pico → RNF-04 |
| P3 | ¿Cómo se registra hoy una incidencia, paso por paso, desde que el cliente llama hasta que el técnico sale? | Proceso actual y herramientas |
| P4 | ¿Qué herramientas usan (hoja de cálculo, WhatsApp, cuaderno, sistema anterior) y quién las administra? | Punto de partida real |

## Bloque 2 — Tiempos y errores (12 min)

| # | Pregunta | Dato que produce |
|---|---|---|
| P5 | ¿Cuánto tarda registrar una incidencia, desde que empieza la llamada hasta que queda anotada? | Tiempo de registro → RF-01 |
| P6 | ¿Cuánto tarda en asignarse a un técnico? ¿Qué pasa si el técnico está ocupado? | Tiempo de asignación → RF-02 |
| P7 | ¿Cuánto tarda el cliente en recibir una respuesta o una visita? | Primera respuesta |
| P8 | De cada 10 casos, ¿cuántos se duplican, se pierden o se reabren? ¿Por qué? | Tasa de error → RF-01, RF-09 |
| P9 | ¿Cómo se entera el cliente del avance: llamada, WhatsApp, nada? | Necesidad de RF-07 |

## Bloque 3 — SLA, costos y disponibilidad (12 min)

| # | Pregunta | Dato que produce |
|---|---|---|
| P10 | ¿Tienen un tiempo de compromiso con el cliente (SLA)? ¿Cuántas horas y qué pasa si se incumple? | SLA real y consecuencia económica → RNF-01 |
| P11 | ¿Cuántas veces al mes se incumple y cuánto cuesta cada incumplimiento (multa, descuento, cliente perdido)? | Costo del problema → tabla de consecuencias |
| P12 | ¿En qué horario se atiende? ¿Hay fines de semana o emergencias nocturnas? | Ventana de disponibilidad → RNF-01 |
| P13 | ¿Los técnicos trabajan desde el local, desde la calle o desde la casa? ¿Con qué conectividad? | Distribución geográfica → justificación distribuida |

## Bloque 4 — Expectativas y cierre (8 min)

| # | Pregunta | Dato que produce |
|---|---|---|
| P14 | Si esto funcionara bien, ¿qué número le gustaría ver bajar en tres meses y a cuánto? | Indicador de éxito → objetivos específicos |
| P15 | ¿Qué no puede pasar nunca? (perder un caso, mostrar un estado falso, cobrar dos veces) | Datos críticos → CAP/PACELC |

## Cierre

1. Repetir en voz alta las tres o cuatro cifras clave para que el entrevistado las confirme.
2. Preguntar si hay alguien más a quien valga la pena entrevistar.
3. Firmar el acta en ese momento.
4. Agradecer y acordar si se puede volver a consultar por dudas.

## Errores que arruinan la entrevista

- Preguntar «¿le gustaría un sistema?»: la respuesta no sirve como requisito.
- Aceptar «es rápido» o «más o menos»: pedir el número o el caso concreto.
- Grabar sin avisar o sin consentimiento.
- Escribir el acta dos días después y pedir la firma por mensajería.
